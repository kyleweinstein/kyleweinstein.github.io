# The Forward-Looking Trader

A 24-week, Druckenmiller- and Soros-inspired curriculum in forecasting, investment research, execution and risk. Original educational synthesis; not investment advice and not a reproduction of any investor's method.

**Release R1 (16 Nov 2026):** course architecture plus the first complete teaching unit. One of 24 lessons is authored.

| File | What it is |
|---|---|
| `00_Curriculum_Blueprint.docx` | Course thesis, all 24 weeks, labs, cases, assessment plan, glossary, source map |
| `01_Module_1_Learner_Guide.docx` | Lesson 1, "Invest in the Future, Not the Present" (Lessons 2–4 outlined only) |
| `01_Module_1_Instructor_Key.docx` | Lesson 1 solutions, rubric, anticipated errors, committee questions |
| `Forecast_Registry.xlsx` | Prediction registry, revision log, Brier/calibration scoring, Lesson 1 scenario exercise |
| `Industry_Foresight_Template.docx` | Reusable 18–24-month forecast-to-trade memo |
| `Source_Register.xlsx` | Sources, claim-level mapping and verification grades |
| `Project_Progress_Log.docx` | Decisions, QA findings, unverified points, next steps |

Start with the Learner Guide and keep `Forecast_Registry.xlsx` open beside it.

## Rebuilding

The documents are generated by the scripts in `build/` (Node `docx` package; Python `openpyxl`).

```bash
cd build
node doc_blueprint.js && node doc_m1_learner.js && node doc_m1_key.js && node doc_template.js && node doc_log.js
python3 build_workbooks.py && python3 build_sources.py
```

Open `Forecast_Registry.xlsx` in Excel or LibreOffice once after rebuilding so formula values are calculated.
